# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/KROWIEL/self-hosted/security/advisories/new)
with steps to reproduce and the affected version.

You should get a first reply within a week. Fixes are released as a new version
and credited in the advisory unless you prefer otherwise.

## Supported versions

Security fixes go into the latest release. Upgrade by re-running the install
command, see [`docs/INSTALL.md`](docs/INSTALL.md#upgrades).
