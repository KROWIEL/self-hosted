# Runbook: Master key rotation

## Контекст
MVP использует single active `MASTER_ENCRYPTION_KEY`.  
Ротация выполняется вручную, с контролируемым окном обслуживания.

## Подготовка
1. Сгенерировать новый ключ (32 bytes, base64).
2. Сохранить старый и новый ключ в безопасном месте.
3. Убедиться, что есть доступ к API и БД.

## Процедура (MVP)
1. Перевести систему в maintenance-режим (остановить операции deploy/route changes).
2. Запустить скрипт миграции секретов (добавляется отдельно):\n
   - читать шифротекст старым ключом,\n
   - перешифровать новым ключом,\n
   - обновить запись.
3. Обновить `MASTER_ENCRYPTION_KEY` в env API.
4. Перезапустить API.
5. Прогнать smoke:
   - чтение app env vars
   - deploy с git credentials
   - route sync
6. Зафиксировать событие ротации в audit log.

## Rollback
Если после ротации операции с секретами не проходят:
1. Откатить env на старый key.
2. Перезапустить API.
3. Проверить восстановление операций.
