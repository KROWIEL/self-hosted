Deploy apps to servers you own

Self-Hosted builds your apps from git, Docker images or Compose files and runs them over HTTPS on your own machines. One panel for one VPS or a whole rack, free and MIT-licensed.

curl -fsSL https://raw.githubusercontent.com/KROWIEL/self-hosted/main/deploy/install.sh | sudo sh

Run it on a Linux server with a domain pointing at it. It installs Docker if needed and prints your admin password.

What it does

Deploy from anywhere
Build a git repository with a template, its own Dockerfile or Nixpacks, run a registry image, or start a Compose stack.
250+ apps in one click
Immich, Jellyfin, Gitea, Vaultwarden, Ollama and more from the built-in catalog.
Databases with backups
PostgreSQL and MySQL per project, scheduled backups, restore, and copies to S3, GCS, Azure or SFTP.
Releases without downtime
Blue-green deploys wait for a health check, and any previous image is one click away.
HTTPS on every domain
Let's Encrypt certificates per domain or as a wildcard, or upload your own.
Many servers, one panel
A small agent on each machine, added with one command. Servers behind NAT go online through a reverse tunnel.
Previews for every pull request
GitHub and GitLab webhooks spin up a disposable environment per branch or PR.
Built for teams
Projects with CPU and RAM quotas, four roles, an audit log, single sign-on and two-factor sign-in.
Everything you watch
Live logs, metrics history, a terminal in the browser, and alerts to Discord, Slack, Telegram or a webhook.

Install on your server

You need a Linux server with 2 GB of RAM or more (Ubuntu 22.04+ or Debian 12+ recommended), root access, and ports 80, 443 and 8443 open.

  1. Point a domain at the server

    Create an A record such as panel.example.com with the server's IP. The certificate is requested on first start, so do this first.

  2. Run the installer

    It asks for the domain and an email for Let's Encrypt, generates every secret, starts the panel and prints the administrator password.

    curl -fsSL https://raw.githubusercontent.com/KROWIEL/self-hosted/main/deploy/install.sh | sudo sh

  3. Connect the server as a node

    Sign in, open Nodes → Add remote node, enter the server's IP and run the command the panel shows. The agent it installs builds and runs your apps.

  4. Deploy

    Create a project, add a service from git, an image or the catalog, attach a domain and press deploy.

More servers and upgrades

Prepare each extra server with the node mode, then add it from Nodes the same way:

curl -fsSL https://raw.githubusercontent.com/KROWIEL/self-hosted/main/deploy/install.sh | sudo sh -s node

To upgrade, run the install command again. Settings and data stay in /opt/selfhosted, and database migrations run on start. The install guide covers wildcard certificates, backups and troubleshooting.

Questions

Is it really free?

Yes. The code is MIT-licensed: use it, change it, sell it or host it for others. There are no paid plans, license keys or limits on servers and users.

Do I need Kubernetes?

No. Every server runs plain Docker with a small agent. Traefik on each server handles HTTPS.

Can I run it at home behind NAT?

Yes. Rent the smallest public VPS you can find and use Exposure in the panel: it relays ports 80 and 443 from the VPS to your home server.

Which architectures are supported?

Linux on x86-64 and ARM64, for both the panel and the agent.

How do I report a bug or a vulnerability?

Bugs go to GitHub issues. Vulnerabilities go through a private security advisory.
