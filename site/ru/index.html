Деплой приложений на свои серверы

Self-Hosted собирает приложения из git, Docker-образов или Compose-файлов и запускает их по HTTPS на ваших машинах. Одна панель и для одного VPS, и для целой стойки. Бесплатно, лицензия MIT.

curl -fsSL https://raw.githubusercontent.com/KROWIEL/self-hosted/main/deploy/install.sh | sudo sh

Выполните на Linux-сервере, на который указывает домен. Скрипт при необходимости поставит Docker и выведет пароль администратора.

Что умеет

Деплой из любого источника
Сборка git-репозитория по шаблону, его Dockerfile или через Nixpacks, запуск образа из registry или Compose-стека.
250+ приложений в один клик
Immich, Jellyfin, Gitea, Vaultwarden, Ollama и другие из встроенного каталога.
Базы данных с бэкапами
PostgreSQL и MySQL на проект, бэкапы по расписанию, восстановление и копии в S3, GCS, Azure или SFTP.
Релизы без простоя
Blue-green деплой ждёт проверки health, а любой предыдущий образ возвращается одним кликом.
HTTPS на каждом домене
Сертификаты Let's Encrypt на домен или wildcard, либо ваши собственные.
Много серверов, одна панель
Небольшой агент на каждой машине, подключается одной командой. Серверы за NAT выходят в сеть через обратный туннель.
Превью для каждого pull request
Вебхуки GitHub и GitLab поднимают временное окружение на ветку или PR.
Для команд
Проекты с квотами CPU и RAM, четыре роли, журнал аудита, единый вход и двухфакторная аутентификация.
Всё под наблюдением
Живые логи, история метрик, терминал в браузере и оповещения в Discord, Slack, Telegram или webhook.

Установка на сервер

Нужен Linux-сервер от 2 ГБ ОЗУ (рекомендуются Ubuntu 22.04+ или Debian 12+), права root и открытые порты 80, 443 и 8443.

  1. Направьте домен на сервер

    Создайте запись A, например panel.example.com, с IP сервера. Сертификат запрашивается при первом запуске, поэтому сделайте это заранее.

  2. Запустите установщик

    Он спросит домен и email для Let's Encrypt, сгенерирует все секреты, запустит панель и выведет пароль администратора.

    curl -fsSL https://raw.githubusercontent.com/KROWIEL/self-hosted/main/deploy/install.sh | sudo sh

  3. Подключите сервер как ноду

    Войдите, откройте Ноды → Добавить удалённую ноду, укажите IP сервера и выполните показанную команду. Установленный ею агент собирает и запускает ваши приложения.

  4. Деплойте

    Создайте проект, добавьте сервис из git, образа или каталога, привяжите домен и запустите деплой.

Другие серверы и обновления

Каждый дополнительный сервер подготовьте в режиме ноды, затем подключите его через Ноды так же:

curl -fsSL https://raw.githubusercontent.com/KROWIEL/self-hosted/main/deploy/install.sh | sudo sh -s node

Для обновления запустите команду установки ещё раз. Настройки и данные остаются в /opt/selfhosted, миграции базы применяются при старте. В инструкции по установке есть wildcard-сертификаты, бэкапы и решение проблем.

Вопросы

Это правда бесплатно?

Да. Код под лицензией MIT: используйте, изменяйте, продавайте и хостите для других. Нет платных тарифов, ключей лицензии и ограничений по серверам и пользователям.

Нужен ли Kubernetes?

Нет. На каждом сервере обычный Docker и небольшой агент. HTTPS на каждом сервере обслуживает Traefik.

Можно запустить дома за NAT?

Да. Возьмите самый маленький VPS с белым IP и используйте раздел Публикация в панели: он пробрасывает порты 80 и 443 с VPS на домашний сервер.

Какие архитектуры поддерживаются?

Linux на x86-64 и ARM64, и для панели, и для агента.

Как сообщить об ошибке или уязвимости?

Ошибки — в GitHub issues. Уязвимости — через закрытое security advisory.
